## Regression boundaries to preserve

- Actual native-frame drawing must suppress duplicate subtitles; callback delivery or a fixture that manually orders overlay calls is insufficient.
- Ordinary native `/playsound` packets must remain native; feature delivery uses the explicit shared semantic envelope and negotiated capability.
- Body and lifecycle both participate in idempotence; changed lifecycle cannot retain obsolete fade/retry behavior.
- Reload invalidation must follow native sound-resource commit, clear missing-sample caches and restore actual playback after a bad replacement pack is removed.
- Private channel projection must not duplicate public transfer audio. Unchanged sources must not create per-tick handles/suppliers or add heartbeat traffic.
- Real GUI/chat input paths must be distinguished from direct handler calls. Ordinary Infuser slots remain free of custom acknowledgement; confirmed Focus changes remain audible.
- Muted audio plus Show Subtitles On must retain eligible semantic captions; Off suppresses them, with neutral private text and no hidden-playback workaround.

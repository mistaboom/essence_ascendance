# Players and the Ascendance Archive

[Home](https://github.com/mistaboom/essence_ascendance/wiki/Home) · [Player commands](https://github.com/mistaboom/essence_ascendance/wiki/Player-Commands)

**The Ascendance Archive is the gameplay guide.** It explains Essences, Skills, Bonuses, Ascension, equipment, machines and cooperative play. Its current values come from the server you are connected to, so it is more useful than a wiki table copied from another pack.

## Get and open the Archive

The mod normally delivers an Archive when you first reach Dormant. Use the item in either hand to open it; no nearby machine or operator permission is needed.

To craft a replacement, place these in one vertical column of a crafting table:

```text
Stick
Raw Latent Ore
Stick
```

The shipped recipe is shaped. A pack's datapacks can change it, so check recipe browsing if the pack supplies a different recipe. Losing the delivered book does not trigger another automatic gift. An operator can replace it with `/essence admin player guide give`.

## Where to look

| You need | Archive destination |
| --- | --- |
| First steps and connected lessons | **Guide** |
| Skills, Bonuses, equipment and machine details | **Reference**, or search by name |
| Item Essence yields | **Reference → Essences → Item Yields** |
| The Ascendance Glaive and two-handed combat | **Guide → Equipment → Ascendance Glaive**, its Reference entry, or search **glaive** |
| Cooperative play | Search **Teams and Shared Essence** |

Use the Archive's back/forward arrows and tab scrolling to navigate. Long item names are shortened in constrained lists; hovering reveals more of the name. Values can take a moment to arrive after joining or rebuilding balance. Persistent loading is something to report to the server administrator, not a zero-value result.

Pack makers should use [Configuration](https://github.com/mistaboom/essence_ascendance/wiki/Configuration) to change the server's balance, then rebuild and check the result in game. Players do not need to edit those files or generate their own balance.

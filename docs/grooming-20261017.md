## Playtesting

This revision changes item identities and generated balance evidence. Use a fresh test world. With Minecraft closed, preserve desired manual config edits separately, then remove `generated_balance.json.gz` and generated `bonus_progression.toml` from `config/essence_ascendance` to request fresh automatic defaults on startup. If deliberately keeping an existing world/config, remove the Bonus defaults while closed and use `/essence admin balance rebuild` after loading. Existing Bonus config entries intentionally pin their values. Keep your skill-layout config. No compatibility migration is provided.

Custom health progression, opaque callbacks, catalyst wear and unknown machine costs remain outside the generic scan. The bounded outfit search may miss unusual cross-piece synergies. Native Tool rule peaks may be specialized speeds, not a speed achievable on every block; actual mining still uses native block rules. Reference bands describe registered default equipment, not proof of acquisition difficulty. Exact unnamed items, creative/JEI presentation and the reported small-window rendering still need human visual review. No live screenshots were used to claim visual acceptance.

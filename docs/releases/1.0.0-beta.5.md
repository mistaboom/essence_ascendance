# Essence Ascendance 1.0.0-beta.5

**A new world is required when upgrading from beta.4 or earlier.** This multiplayer update changes how Essence Ascendance saves player balances, team membership and machine ownership. Older EA saves are incompatible and there is no automatic migration. Back up and keep your existing world with its matching older mod version. Do not delete individual player-data files or edit save-version numbers to force an upgrade.

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Install the matching beta.5 build on the server and every client. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API.

## Multiplayer and shared infrastructure

- Adds native teams and optional FTB Teams/Open Parties and Claims membership integration.
- Team members share Stored Essence and infrastructure; Available Essence and invested progression stay personal. Joining shares existing Stored Essence, and departures retain the member's recorded remaining share.
- Supports concurrent Crucible channeling and shared machine consumers, with coordinated accounting and machine access checks.
- Adds team/access interfaces, clearer machine ownership and link status, and readable team, machine and membership commands.
- Improves Infuser start/approval, soulbinding, paid-work recovery and automation behavior.
- Updates the Ascendance Archive and the [wiki](https://github.com/mistaboom/essence_ascendance/wiki) for multiplayer mechanics, commands and administration.

## Fixes and administration

- Requires an explicit team name when approving a request creates a native team; existing-team approvals retain their name.
- Extends provider-activation review to about five minutes at normal server speed, with a visible countdown, explicit expiry guidance and clickable command suggestions.
- Accepts FTB Teams **2101.1.11** with FTB Library **2101.1.30, 2101.1.36 or 2101.1.37**. For membership and FTB Quests evidence together, use Quests **2101.1.36**, Teams **2101.1.11**, Library **2101.1.36 or 2101.1.37**, and Architectury **13.0.11**. OpenPAC membership supports **0.32.7**. Use the correct loader variants and their required dependencies.
- Serializes mod-site publishing jobs to reduce upload contention seen in previous releases.

## Before starting your new world

Install your chosen team provider before the world's first startup. With the default AUTO selection, supported FTB Teams takes priority, then supported OpenPAC; otherwise EA uses native membership when no unsupported external provider blocks selection. An established world retains its selected provider. Switching providers later does **not** migrate existing machine ownership.

This is a beta release. Automated accounting, command, presentation and loader checks cover the tested paths; real FTB activation and ownership of a newly placed Crucible have also been confirmed. Broader two-client, offline-member, unloaded-machine, restart and graphical acceptance checks remain ongoing. Recovery from a crash between player-data and chunk saves is not guaranteed. Please include your loader, dependency versions, reproduction steps and relevant logs in [bug reports](https://github.com/mistaboom/essence_ascendance/issues).

# Essence Ascendance 1.0.0-beta.7

**Following the major balance overhaul, this release is currently balanced for vanilla only.** Modpack balancing, including ATM10, is unfinished. Successful loading and automated checks do not mean a modpack's item values, equipment, Bonuses or Skills are correctly balanced. Further tuning and investigation will follow in a later update.

**Use a fresh world and fresh Essence Ascendance configuration.** This overhaul does not migrate earlier saves or generated balance settings. Back up your existing installation before starting over.

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Install matching versions on the server and every client. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API.

## Balance overhaul

- Replaces the old valuation engine with a simpler, bounded system based on shared item properties, common tags and recipes. Material properties, declared rarity and reversible crafting conversions help distinguish values without bespoke mod rules.
- Removes quest-based inference, bespoke KubeJS inspection and content-specific valuation adapters. JEI and functional FTB integrations remain.
- Moves Skill placement to an editable configuration with the default tree layout. Rank counts and effects remain generated.
- Generates editable Bonus start/end tiers and minimum/maximum rewards. Meaningful minimums remain, and Bonuses can finish before Transcendent.
- Uses additional damage points for damage Bonuses and scales their requests against the matching weapon family. This is an initial improvement, not completed modpack balance.

## Fixes and presentation

- Bonus access follows the player's tier: intact eligible Dormant gear can channel a Transcendent player's earned Bonus while retaining Dormant innate stats.
- Bonus tooltip tiers run from Transcendent down to Dormant, with `N/A` outside the active range.
- Prevents injected inventory buttons from overlapping the shared fullscreen interfaces.
- Handles extended item rarities without aborting balance generation.

## Known limitations

Modpack Bonus and Skill scaling, some equipment and ingredient values, generated ore listings, narrow Archive layouts and blank-name yield entries still need investigation. Tool Instinct startup behavior and the JEI refresh delay after rebuilding balance are also reported issues. These are deferred, not claimed fixed in this release.

# Essence Ascendance 1.0.0-beta.9

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Install matching versions on the server and every client. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. JEI remains optional.

## Ascendance Glaive

- Adds a normal six-tier, two-handed Ascendance Glaive, using the existing equipment stats, Infuser progression, durability, fracture, repair and soulbound systems.
- Left click performs a 120-degree swipe; each valid victim receives a full resolved hit before its defenses. Right click performs a faster half-damage stab that stops at its first physical contact. Both share recovery and retain free camera movement.
- Ordinary tier ranges are **4 / 5 / 6 / 8 / 9 / 10 blocks**. Eligible personalized Transcendent glaives can reach **30 blocks**. Long-range actions use bounded sampled collision for performance; very thin or grazing contacts between samples can be missed.
- Craft the Latent glaive with three Latent Ingots and two sticks, then use the normal five Infuser upgrades. Check the Archive or recipe browser for the shaped recipe and active-server requirements.
- Keeps offhand inventory operations ordinary. Empty hands and approved passive items such as Totems of Undying allow attacks; incompatible offhand equipment produces a throttled **Incompatible offhand item** message. Shields cannot block or provide this mod's held-shield reflection while two-handed gear is selected. Totems still function normally.
- Adds trident-style rest and shoulder-driven attacks, a rigid blade and butt, and an extending shaft that repeats the original three wood pixels without stretching. Both blade and butt accents share tier/personalized tint and glow. Tiny diagonal shaft pixels can shimmer at distant or oblique views.
- Adds eligible personalized glaive presentation/range and flavor text for personalized equipment, while preserving the existing fishing-rod perks and normal fallback rules.

## Archive and documentation

- Adds an Ascendance Glaive Guide lesson, searchable combat/offhand guidance and live equipment/action Reference details.
- Allows Guide sections with multiple lessons to use the existing entry navigator, while single-lesson sections retain their full reading width.
- Refreshes the pack-maker wiki around configuration, generation, overrides, reports and administration. Players should use the in-game Archive for gameplay lessons and current server values.

## Updating and verification

Back up your world and configuration before updating. **Beta.9 introduces no additional saved-format break over beta.8 and requires no new world/profile reset.** When updating from beta.7 or earlier, the beta.8 fresh-world/fresh-configuration requirement still applies; older item identifiers and generated formats are not migrated automatically.

The full common regression suite, both loader builds and native combat/policy/presentation/progression fixtures passed locally. This does not certify every modpack, GPU/shader combination, real multiplayer visual case or saved-world recovery path; those remain integration checks. The earlier 16/64-block prototypes are not gameplay ranges in this release.

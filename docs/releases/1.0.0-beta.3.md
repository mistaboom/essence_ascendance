# Essence Ascendance 1.0.0-beta.3

For Minecraft 1.21.1, on Fabric and NeoForge.

## Progression and storage

- Dormant mining tools now start at the native iron-pickaxe speed benchmark. Latent tools rise with that entry point, while later tiers retain a smooth curve toward the pack-calibrated maximum.
- Rebalanced the shared purchase budgets: early skill ranks cost more and Bonus states cost less. Prices still follow the loaded pack's resource supply, progression effort, native effects and conditions.
- Increased Crucible base storage and every pylon tier's storage contribution tenfold. Transfer speed, throughput and the tier curve remain separate.
- Tool Instinct remains available, but no skill requires purchasing it.

## Enchantments and survival

- Enchanted-book dissolution now accounts for actual enchantment type and level, with category-specific yields and diminishing returns for combined enchantments. Archive entries and tooltips use the same values.
- Shared native enchantment evidence also informs skill and Bonus competition. Unsupported custom effects remain explicit instead of receiving invented strength.
- Material valuation now distinguishes functional demand from repeated decorative recipes and accounts for native harvest quantities, correcting inflated copper values.
- Restful Mending repairs durability points rather than a percentage of maximum durability: at least 1 point/second for the first rank and +1 point/second for another meaningful rank. Stronger generated ranks remain possible.
- Metabolic Mending uses durability points per intrinsic food point. Inner Sustenance keeps its recovery but no longer grants full-reserve hunger immunity. Automatic Feast Reflex meals obey the generated eating cadence.
- Doubled the default Latent awakening effort. Ascendance Archive delivery is unchanged.
- Added the new Ascendance Matrix artwork and updated crafting recipes.
- Improved acquisition-source propagation, probabilistic renewable recipes, cached recipe-ingredient handling and saved-rank compatibility.

## Updating an existing world

Run `/essence admin balance rebuild` to publish the new generated balance. Existing human configuration is preserved: set `onboarding_effort_fraction = 1.0` before rebuilding if you want the longer opening and your file still says `0.5`. Existing player progress and purchase/refund records are retained.

Custom-mod mechanics without supported evidence can remain unvalued or conservative. This beta does not claim complete compatibility with every modded effect.

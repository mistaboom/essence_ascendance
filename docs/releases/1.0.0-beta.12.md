# Essence Ascendance 1.0.0-beta.12

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose the download matching both your Minecraft version and loader, and install the matching build on the server and every client. Minecraft 1.21.1 uses **Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. JEI remains optional.

## Minecraft 26.1.2 support

- Adds Fabric and NeoForge downloads for Minecraft 26.1.2 alongside the existing Minecraft 1.21.1 builds.
- Shares gameplay, machines, progression, networking and interface behavior across the supported versions, with native rendering, persistence and loader integrations for each target.
- Includes the recent glaive input and rapid consecutive attack fixes.

## Modpack compatibility

- Fixes a NeoForge 26.1.2 startup crash encountered in **All the Mods 11**. Explosion guard and Containment Field hooks now select the correct native explosion method while preserving normal damage, knockback and player synchronization.
- Pack Tester now recognizes the unused Forge metadata pointer shipped by TrimsEffects in **FTB Evolution 2**, allowing the pack's supported Minecraft/NeoForge target to resolve correctly. Required dependency and duplicate-mod checks remain active.
- Adds automated checks for explosion hook selection and actual native explosion behavior, including Containment Field activation and removal.

## Updating

**Beta.12 adds no saved-format or configuration break over beta.11 and requires no new world/profile reset when updating within the same Minecraft version.** The beta.8 fresh-world/fresh-configuration requirement still applies when updating from beta.7 or earlier; see the earlier release notes for that upgrade boundary.

# Essence Ascendance 1.0.0-beta.2

For Minecraft 1.21.1 on Fabric and NeoForge.

- Fixed an Ore Sight error that could disconnect players from LAN or multiplayer worlds and kick them again after reconnecting. Ore detection and Nature's Boon now read the active saved economy instead of invoking balance generation during gameplay.
- Removed amethyst from the Channelstone, Ascendance Nexus, Essence Infuser, and Essence Pylon crafting recipes. Essence Focus, Ascendance Matrix, and Ascendance Caster still require amethyst.
- Latent pickaxes now have at least iron-pickaxe mining capability. Higher tiers keep their existing progression toward the pack's maximum harvest level. The minimum also applies when loading existing saved balance profiles.

Install the matching updated jar on the host/server and every client. Existing worlds and player progression are preserved.

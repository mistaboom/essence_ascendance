# Essence Ascendance 1.0.0-beta.15

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose
the download matching your Minecraft version and loader. Minecraft 1.21.1 uses
**Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and
Architectury API; NeoForge requires Architectury API. JEI remains optional.

## 69 achievements

- Adds 69 achievements covering progression, equipment, machines, combat,
  fishing-rod movement, survival, companions, gathering and farming.
- Shows the full achievement tree in the **Essence Ascendance** advancement tab
  from your first login. Individual achievements retain their own names, icons,
  descriptions and native Minecraft toasts.
- Tracks successful server-side actions and credits the responsible player.
  Shared machines distinguish the operator from their teammates and owner.
- Preserves completed achievements through Minecraft's advancement saves, with
  bounded saved partial progress for the rules that need it.
- Uses existing item artwork and native presentation. Achievements add no rewards,
  skills, damage bonuses or new requirements for ascension.

## Reliability

- Prevents duplicate combat callbacks from using up tracked action slots.
- Prevents interrupted movement from counting unchanged full momentum as a new
  achievement transition.
- Rejects copied or replaced Latent Ore as evidence of natural generation.
- Reduces repeated work when expiring completed operation receipts.

## Updating and commands

Updating from beta.14 within the same Minecraft version does **not** require a
world, player-progress or configuration reset. Existing legacy Water Skiing
progress is preserved separately; it does not automatically earn a new achievement.
Earlier fresh-world requirements still apply when upgrading from beta.7 or older.

For an administrative display preview, use:

```text
/advancement grant @s from essence_ascendance:achievements/a022
/advancement revoke @s from essence_ascendance:achievements/a022
```

These affect the 69 selected achievements. Revoking completion does not erase
saved lifetime partial progress. Vanilla advancement tabs appear through their
normal discovery rules; obtaining a crafting table reveals the Minecraft tab.

Natural-origin achievements require positively observed generated ore. Unknown
old ore is not treated as naturally generated, and disabling required skills or
eligible ore generation can make the corresponding achievement unavailable.

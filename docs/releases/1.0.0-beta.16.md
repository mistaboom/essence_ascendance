# Essence Ascendance 1.0.0-beta.16

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose
the download matching your Minecraft version and loader. Minecraft 1.21.1 uses
**Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and
Architectury API; NeoForge requires Architectury API. JEI and FTB Teams are optional.

## FTB Teams compatibility

- Removes the FTB Teams and FTB Library version allowlist. Essence Ascendance
  attempts the installed API, so a compatible update needs no version-list change.
- Fixes personal Crucibles and other devices being blocked by an unlisted FTB
  version. Solo players can use their own devices without creating a party.
- Continues checking membership when optional FTB event hooks fail, using live
  authorization and periodic roster checks.
- Falls back to Essence Ascendance's built-in teams if the membership API actually
  fails or an established provider is removed. The last confirmed teams, ownership
  history and exact Essence balances are preserved, including unloaded devices.
- Makes the built-in team controls available after fallback, even with FTB Teams
  still installed. Fallback persists through restart; administrators can inspect
  `/essence admin membership status` and explicitly reactivate a repaired provider.

Normal startup and team changes still wait for confirmed membership. Recovery
does not invent access to devices with unknown ownership.

## Updating

Update the mod on both the server and clients. Updating from beta.15 within the
same Minecraft version requires **no world, player-progress or configuration reset,
and no balance rebuild**. Existing settings and generated balance remain in place.
The earlier fresh-world requirement still applies when upgrading from beta.7 or older.

Pack makers can also find editable, versioned configuration downloads in the
[wiki preset catalog](https://github.com/mistaboom/essence_ascendance/wiki/Config-Presets).
Each preset lists its own tested pack version and playtest status.

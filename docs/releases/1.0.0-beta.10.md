# Essence Ascendance 1.0.0-beta.10

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Install matching versions on the server and every client. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. JEI remains optional.

## Equipment fixes

- Personalized Ascendance Glaives and Fishing Rods now keep their custom colors, names and eligible perks throughout their associated player's inventory, including unselected hotbar slots and the inventory cursor. Both use the same personalization overlay. Dropping, storing or transferring the item restores its ordinary tier appearance and behavior.
- Right-click block interactions, machine menus and item frames take priority over glaive stabs and fishing-rod casting/reeling. Weapon use follows when the normal interaction does not consume the click; look away from an interactive target to stab or reel.
- Interaction animations no longer trigger unintended glaive swipes. Both weapons can be placed in item frames normally.
- Includes refreshed glaive blade and butt shading, preserving the existing pixel silhouettes and geometry.

## Modpack startup fix

- Fixes a server-startup crash encountered in **All the Mods 10** when Supplementaries equips its simulated player while discovering faucet behavior. Equipment policy and glaive animation updates now check for a live play connection before negotiating network support. Simulated players still receive normal equipment-rule evaluation.

## Updating and verification

**Beta.10 adds no saved-format or configuration break over beta.9 and requires no new world/profile reset.** The beta.8 fresh-world/fresh-configuration requirement still applies when updating from beta.7 or earlier; see the earlier release notes for that upgrade boundary.

Regression coverage includes personalized inventory/cursor/drop/transfer behavior, native block-menu and item-frame interactions, and simulated players without a live network channel on both loaders. The startup crash was reproduced before the connection fix. Full ATM10 gameplay remains a separate integration check.

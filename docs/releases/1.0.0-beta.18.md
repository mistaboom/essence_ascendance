# Essence Ascendance 1.0.0-beta.18

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose
the download matching your Minecraft version and loader. Minecraft 1.21.1 uses
**Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and
Architectury API; NeoForge requires Architectury API. JEI and FTB Teams are optional.

## Minecraft 26 skill fixes

- Restores Ore Sight and Threat Sense outlines, along with other shared skill
  line effects, after Minecraft 26 changed the line-rendering format.
- Keeps Essence Wings gliding continuously without an Elytra, fixing the
  flickering active HUD state and interrupted vanilla firework boosts.
- Restores Vector Boost's fresh-Jump activation during an Essence Wings glide.

## Nexus and commands

- The Ascendance Nexus now uses the same ordinary fullscreen screen foundation
  as the Archive. Inventory overlays such as TrashSlot no longer attach to it.
  Server-side transaction checks and the existing exit/apply/discard flow remain.
- Fixes skill-grant and unknown-skill command messages rejecting identifiers
  under Minecraft 26's stricter text validation.
- Fixes admin activation of Sanctuary, Industrious Presence and Containment
  Field, including repeated activation without changing the rest of the loadout.

## Updating

Update both server and clients. Updating from beta.17 within the same Minecraft
version requires **no world, player-progress or configuration reset, and no
balance rebuild**. Installing or changing a configuration preset still requires
its documented rebuild. The earlier fresh-world requirement still applies when
upgrading from beta.7 or older.

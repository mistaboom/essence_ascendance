# Essence Ascendance 1.0.0-beta.11

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Install matching versions on the server and every client. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. JEI remains optional.

## Glaive artwork and animation

- Includes the updated glaive blade, blade accent, and longer shaft artwork, with matching blade collision bounds.
- The head and upper shaft now slide together smoothly during extension and retraction. The grip stays anchored in the hand, with overlapping shaft sections hidden inside the palm to prevent gaps.
- The glaive returns to rest when retraction finishes, independently of the attack recharge indicator. It no longer holds the final animation frame while recharge continues.
- Brief, smooth pivots connect rest, attack, and return poses instead of snapping to the 45-degree attack angle.
- Preserves server-controlled damage timing, tier reach, and attack-speed bonuses. Rapid consecutive attacks finish the previous return before preparing the next attack without delaying damage playback.
- First-person transitions account for camera rotation, walking bob, and differing hand/world fields of view.

## Updating

**Beta.11 adds no saved-format or configuration break over beta.10 and requires no new world/profile reset.** The beta.8 fresh-world/fresh-configuration requirement still applies when updating from beta.7 or earlier; see the earlier release notes for that upgrade boundary.

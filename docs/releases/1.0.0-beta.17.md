# Essence Ascendance 1.0.0-beta.17

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose
the download matching your Minecraft version and loader. Minecraft 1.21.1 uses
**Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and
Architectury API; NeoForge requires Architectury API. JEI and FTB Teams are optional.

## Reopening single-player worlds

Fixes an equipment-rule refresh race found while testing the ATM11 preset.
After leaving a world, opening it again could display a datapack-loading failure
because the refresh still referenced a disconnecting player. Equipment rules
continue to refresh for connected players when data is reloaded.

This includes beta.16's FTB Teams compatibility changes: runtime API detection
without version allowlists, personal-device access without creating a party,
and recovery to built-in teams when an established integration fails.

## Configuration presets

The expandable [wiki preset catalog](https://github.com/mistaboom/essence_ascendance/wiki/Config-Presets)
includes editable pack settings, installation instructions and revision checksums.
The ATM11 0.14.0-beta preset targets solo Normal play with automation and a full
Essence Ascendance progression path. Each preset lists its own test status;
numeric validation is separate from a complete progression playthrough.

## Updating

Update both server and clients. Updating from beta.15 or beta.16 within the same
Minecraft version requires **no world, player-progress or configuration reset,
and no balance rebuild**. Installing or changing a configuration preset still
requires its documented rebuild. The earlier fresh-world requirement still
applies when upgrading from beta.7 or older.

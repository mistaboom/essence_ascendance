# Essence Ascendance 1.0.0-beta.8

Minecraft **1.21.1**, **Java 21**, **Fabric or NeoForge**. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. Install matching versions on the server and every client.

**Start with fresh worlds and Essence Ascendance configuration.** Item identifiers and generated configuration formats have changed without migration. Back up existing installations before updating.

## Balance and configuration

- Improves generic pack equipment references and Skill/Bonus generation using shared native attributes and tool rules. Vanilla and normal ATM10 passed isolated generation, rebuild and saved-profile restart checks; modpack balance remains approximate and may need tuning.
- Gives Latent gear an iron-era foundation, then scales higher tiers toward measured pack equipment. The Essence Caster deals less damage than the bow, fires faster and has shorter range.
- Adds editable Skill unlock tiers, rank counts and first/maximum stat values in `skill_settings.toml`. Bonus active tiers and effect bounds now live in `bonus_settings.toml`.
- Clarifies global settings, advanced overrides, reports and diagnostics. Apply edited balance settings with `/essence admin balance rebuild`.
- Improves generic recipe quantity and reversible material handling without content-specific valuation rules.

## Equipment, recipes and interface fixes

- Renames the Ascendance Blade to the Ascendance Sword, including its internal identifier.
- Keeps equipment and armor variants ordered from Latent through Transcendent in creative listings and JEI's creative sorting stage.
- Corrects tier-specific crafting and Infuser recipe matching, removes armor-trim recipes, and changes the Archive recipe to a vertical stick, Raw Latent Ore, stick.
- Lists generated Latent Ore variants alongside the existing variants in JEI and creative tabs.
- Improves narrow Archive layouts, long item names, unnamed yield filtering and tab navigation.
- Cleans up the completed Transcendent Ascendance display, small-scale symbols and tier text.
- Improves Tool Instinct's initial mining behavior and avoids repeating JEI search indexing already completed for the current tooltip revision.
- Makes Info, Settings and membership popups move only the JEI area on their actual side, keeping page controls with the items.
- Fixes a JEI startup failure caused by an unavailable internal sorting callback. The corrected integration passed native hook checks with JEI 19.53 on Fabric and 19.54/19.57 on NeoForge; optional late-variant sorting now fails safely if that hook is unavailable.

The added glaive artwork remains an authoring asset; this release does not add a playable glaive. Pack generation checks do not establish perfect valuation or complete gameplay balance for every item and Skill.

# Essence Ascendance 1.0.0-beta.13

Available for **Minecraft 1.21.1 and 26.1.2**, on **Fabric and NeoForge**. Choose the download matching both your Minecraft version and loader, and install the matching build on the server and every client. Minecraft 1.21.1 uses **Java 21**; Minecraft 26.1.2 uses **Java 25**. Fabric requires Fabric API and Architectury API; NeoForge requires Architectury API. JEI remains optional.

## Latent Ore textures

- Fixes a NeoForge Minecraft 26.1.2 host-data refresh bug that could leave Latent Ore displaying its pink-and-black diagnostic texture beside correctly textured ore. Host data now refreshes before the block mesh is rebuilt.
- Uses the same general host-data path for saved blocks, incoming client updates and placed ore. No mod-specific texture adapter is required for this fix.
- Shares identical world and inventory ore images and mipmaps, reducing generated texture allocations while preserving the native host pixels and overlay orientation.

## Cheap bulk materials

- Restores a low-value economy policy for **cobblestone, stone and basalt**, with an estimate ceiling of **1 Essence per block**. Complete recipe constraints may reduce a payout further.
- Keeps the ceiling effective through expensive alternate recipes and reversible compressed forms, so processing cannot create extra Essence from cheap bulk inputs.
- Pack authors can extend or replace the `essence_ascendance:low_value_bulk_materials` item tag for additional bulk sources.

## Memory use

- Shares repeated ingredient alternatives and item identities during balance generation instead of retaining duplicate data for each recipe slot.
- Reuses normalized recipe identities in source diagnostics. Recipe quantities, returned containers and conservation checks are preserved.
- The large recipe stress fixture passes with a 256 MiB heap on both supported Minecraft versions. This measures recipe normalization; the reported ATM11 startup memory crash remains unverified without the tester's crash report.

## Updating

**Updating from beta.12 within the same Minecraft version requires no world, player-progress or configuration reset.** After installing beta.13, run **`/essence admin balance rebuild`** to apply the corrected values to an existing saved balance profile. Normal startup otherwise reuses the saved values.

The beta.8 fresh-world/fresh-configuration requirement still applies when updating from beta.7 or earlier; see the earlier release notes for that upgrade boundary.
